# **Switch it Up! (8 kyu)**

### **Description:**
When provided with a number between `0 - 9`, return it in words. Note that the input is guaranteed to be within the range of `0 - 9`.

Input: `1`

Output: `"One"`.

If your language supports it, try using a [<u>switch statement</u>](https://en.wikipedia.org/wiki/Switch_statement).
